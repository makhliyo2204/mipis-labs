Порядок работы с симулятором

    
  1. Выберите свой номер варианта: N, интервал, время контроля, p_defect и seed заполнятся из таблицы 4.
  2. Перенесите таблицу результатов в отчёт кнопкой «Копировать таблицу»: она вставляется в Word и Excel как таблица.
  3. Запустите код Python у себя и сверьте вывод с таблицей.
  4. Посмотрите анимацию для 1 и для 2 постов: при одном посте очередь растёт почти без остановки, загрузка около 100 %.
  5. Выберите рациональное число постов: ожидание приемлемое, а посты не простаивают большую часть времени.
